# Brand assets — @tufrenperfumero

- `logo-icon.svg` — circular mark (perfume atomizer, wine + gold). Use as the profile picture on TikTok/Instagram/YouTube — it's built with a safe margin so a circular crop won't clip it.
- `wordmark-light.svg` — horizontal logo for light/white backgrounds (thumbnails, blog header).
- `wordmark-dark.svg` — horizontal logo for dark backgrounds (video intros, dark-mode banners).

Palette: wine `#8b2942`, gold `#c49a52`, cream `#f4ece0`, ink `#241f2e`. Keep new graphics (thumbnails, story templates) on these four colors for consistency.
