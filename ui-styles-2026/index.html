Hand-Drawn / Scrapbook / Sticker

A personal, assembled look built from stickers, tape, stamps, snapshots and handwritten touches layered on paper.

Best for: Social products, youth brands, journaling, creator tools, events and community spaces.

Avoid when: The flow is dense or transactional and playful layering would fight a disciplined structure.

Saturday market

Lemon tart, a blue bike and one ticket stub. Pin the best three to the board.

Straighten the notes
  • Wobbly borders
  • Washi tape
  • Die-cut stickers
  • Paper texture
  • Handwritten headings
.note {
  background: #fbd966;
  border-radius: 14px 22px 12px 24px / 24px 12px 22px 14px;
  transform: rotate(-1.2deg);
  box-shadow: 3px 4px 0 rgb(42 34 48 / 0.18);
}
.note::before { /* washi tape */
  content: '';
  background: repeating-linear-gradient(45deg,
    rgb(255 255 255 / 0.55) 0 6px, rgb(255 255 255 / 0.25) 6px 12px);
}
.sticker {
  border: 8px solid #fffdf6;
  filter: drop-shadow(0 3px 2px rgb(0 0 0 / 0.25));
}

Accessibility note

Main risk: Handwriting fonts, saturated colours and tilted layers can hurt legibility and scan order. Mitigation: Handwriting is limited to headings, body copy is a plain sans on opaque paper plates above 4.5:1, tilts stay under 2 degrees (and a switch removes them), and stickers sit around the content, not across it.

Aurora / mesh gradients

Soft, multi-point gradients blend luminous colours into clouds, glows and colour fields behind the interface.

Best for: AI products, SaaS landing pages, premium branding, onboarding and hero backgrounds.

Avoid when: Text would sit directly on the gradient, such as paragraphs or small labels.

Northern lights forecast

Clear skies and a strong green glow are expected after 22:00. Get a nudge when it starts.

Pause the drift
  • Layered radial gradients
  • Blur
  • Teal, green, magenta on navy
  • Solid text plates
.aurora {
  position: absolute;
  inset: 0;
  background:
    radial-gradient(40% 50% at 20% 30%, #2dd4bf, transparent 70%),
    radial-gradient(35% 45% at 75% 25%, #86efac, transparent 70%),
    radial-gradient(40% 50% at 60% 85%, #f0529c, transparent 70%),
    #070f1f;
  filter: blur(40px);
}
.plate {
  background: rgb(7 15 31 / 0.88); /* solid enough for text */
  backdrop-filter: blur(14px);
}

Accessibility note

Main risk: Text contrast varies across a gradient, and slowly moving colour can distract. Mitigation: All text sits on near-opaque navy plates checked above 4.5:1, the drift runs only while the section is visible and motion is allowed, and a switch pauses it.

Data-Dense Utilitarian

Compact spacing, visible structure, tables, restrained colour and functional type with almost no ornament.

Best for: Developer tools, ops, analytics, trading, logistics and internal enterprise software.

Avoid when: The audience is casual or consumer-facing and needs room to breathe.

  width: 100%;
  border-collapse: collapse;
  font: 0.8125rem/1.3 'IBM Plex Mono', ui-monospace, monospace;

  padding: 0.35rem 0.6rem;

  text-align: right;
  font-variant-numeric: tabular-nums;
}
tbody tr:hover { background: #e8eef7; }

Accessibility note

Main risk: Small text, tight rows, small targets and colour-only status make dense screens hard to read. Mitigation: Type stays at 13px or larger in rem, controls are at least 32px tall, every status pairs colour with a shape and a word, and muted greys are checked above 4.5:1.

Blueprint / schematic

A technical-drafting look of thin lines, fine grids, dimension marks and monospace labels on a blue ground.

Best for: Hardware, developer tools and infrastructure, product explainers, posters and instructional content.

Avoid when: The interface is content-heavy and built around long reading.

Accessibility note

Main risk: Thin light lines and light-blue text on navy can drop below readable contrast, and tiny monospace annotations are hard to read. Mitigation: Text is white or pale cyan on the blue at well above 4.5:1, annotations are real text at 0.8125rem or larger, and line-art meets 3:1 (the WCAG 1.4.11 mapping is the author's inference, as the research notes it was not fetched).

Biophilic / organic

Nature-centred interfaces that use organic shapes, earthy colour, natural texture and gentle motion to feel calmer and warmer.

Best for: Wellness, sustainability, and calm or focus products.

Avoid when: The screen is a heavy data or operations tool.

Ten minute forest walk

A guided pause between meetings: slow breathing, birdsong and one question to carry back to your desk.

Still leaves
  • Blob radii
  • Forest and moss greens
  • One amber accent
  • Green-tinted shadows
.card {
  background: #f7f8f3;
  border-radius: 63% 37% 54% 46% / 55% 48% 52% 45%;
  box-shadow: 0 24px 40px -20px rgb(31 77 58 / 0.4);
}
.leaf {
  width: 3rem;
  height: 3rem;
  background: #2f6b4a;
  border-radius: 0 100% 0 100%;
  transform: rotate(-12deg);
}
.cta { background: #e8a33d; color: #14301f; }

Accessibility note

Main risk: Muted earth and green palettes, and text over nature imagery, can lose contrast, and ambient motion can distract. Mitigation: Text is deep forest green on opaque stone surfaces above 4.5:1, no text sits over imagery, and the leaves sway only when motion is allowed and can be stilled with a switch.
